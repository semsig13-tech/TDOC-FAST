# Область применения

Настоящие методические рекомендации распространяются на следующие продукты:

- TER\_Rec15\_Smart1\_R7;
- TER\_Rec15(25)Al1\_L5M;
- TER\_Rec35\_Smart1\_Tie7;
- TER\_Rec35\_Smart1\_Sub7;
- TER\_VCB15\_LD8 (Shell2)\_SRF2;
- TER\_VCB15\_LD8 (Shell2)\_SRD2;
- TER\_VCB15\_LD8 (Shell2)\_SF2;
- TER\_VCB15\_HD1\_3CS\_6VS04 (6VS\_3CAS);
- TER\_VCB15\_Shell2\_3CS\_6VS04 (6VS\_3CAS);
- TER\_VCB15\_MD1\_3CS\_6VS04;
- TER\_OVCB35\_Smart\_7C (7CS/1C/9CS)

Рекомендации распространяются на модули управления CM\_15\_4(5/5С/6) модификацией (220\_1) и выше.

Для получения актуальной версии встроенного ПО (далее - ВПО) и пользовательского ПО (TELARM Lite, Section Tool) необходимо:
1. Открыть актуальную версию документа Совместимость версий продуктов TEL ==\[TER\_SW\_Version\_Control]\(null)==
2. Зайти в раздел нужного продукта;
3. Определить актуальную версию встроенного ПО, исходя из аппаратной части модуля управления (см. [[#Определение аппаратной части модуля управления]]), и совместимые с ней версии пользовательского программного обеспечения - TELARM Lite и Section Tool;
4. Скачать нужные версии ПО по ссылке ==\[Программное обеспечение]\(null)==.

Подайте оперативное питание на все модули управления от сети переменного тока или ТСН. Разъемы питания указаны в таблице [[Реклоузер#^Power-connector|Разъемы питания у модулей управления]].

| Модуль управления | Разъемы питания |
| ----------------- | --------------- |
| CM\_15\_4           | X2, X5          |
| CM\_15\_5           | X4, X7          |
| CM\_15\_6           | X2, X5, X8, X11 |
| СМ\_15\_5С          | S2, D3          |

> **Примечание:**
> Обновлять ПО CM\_15 при питании только от батареи запрещено!

По умолчанию IP-адрес:

- для Wi-Fi: 192.168.100.11;

# Автоматическое обновление ВПО

## Установить соединение с SectionTool

Запуск утилиты осуществляется нажатием кнопки «Обновить» в интерфейсе TELARM Lite:

| ![[media/Параметрирование CM_15/Обновление ВПО/Реклоузер/6.png]] |
| :--------------------------------------------------------------: |
|      **Рис. 6** Кнопка «Обновить» в интерфейсе TELARM Lite       |

Произвести автоматический поиск CM\_15 по интерфейсам кнопкой «Autodetect» / «Автопоиск» или добавить вручную известный IP с помощью кнопки «Add…» / «Добавить…». CM\_15 добавится в базу данных (БД) устройств SectionTool.

|             ![[media/Параметрирование CM_15/Обновление ВПО/Реклоузер/7.png]]             |
| :--------------------------------------------------------------------------------------: |
| **Рис. 7** Автоматический поиск и ручное добавление CM\_15 в список устройств SectionTool |

Выделить необходимое устройство в БД и нажать кнопку «Connect» / «Подключить», предварительно разорвав соединение в TELARM, если оно было ранее установлено. Произойдет подключение.

## Загрузить ВПО

В SectionTool перейти на вкладку «Автоматическое обновление», выбрать соответствующий файл прошивки ВПО (см. [[Реклоузер#^Power-connector|Разъемы питания у модулей управления]]) и нажать «Обновить до версии 78.4.2».

|     ![[media/Параметрирование CM_15/Обновление ВПО/Реклоузер/8.png]]      |
| :-----------------------------------------------------------------------: |
| **Рис. 8** Поле задания файла прошивки для автоматического обновления ВПО |

> **Примечание:**
> Обновление ПО CM\_15 автоматически приведет к выводу защит, переводу в местный режим данного устройства!

Допускается выполнять обновление сразу нескольких СМ\_15. Для этого перед нажатием клавиши «Обновить» необходимо выделить в БД SectionTool необходимые модули управления. (Ctrl+ЛКМ или Shift+ЛКМ).

## Завершение обновления ВПО

Автоматическое обновление выполняется около 10-20 минут.

По завершению автоматического обновления программа сообщит об успешном завершении сообщением со следующим содержанием:

<span style="background-color: gray; color: black; padding: 6px 10px; border-radius: 4px;">
  2026-08-12 15:18:09.370 INFO <b>192.168.102.11 / 0 / 00900005 Updater2000 all software has been upgraded</b>
</span>

При этом SectionTool автоматически восстановит функциональность и другие настройки модуля управления. После таймаута программа автоматически восстановит соединение с модулем.

В случае, если автоматическое обновление ПО выполнить не удалось, появится запись со следующим содержанием:

<span style="background-color: gray; color: red;padding: 6px 10px; border-radius: 4px;">
  2026-08-12 15:25:21.091 ERROR <b>192.168.102.11 / 0 / 00900005 Updater2000 failed: Canceled</b>
</span>

В указанном случае необходимо выполнить перезапуск модуля управления по питанию и выполнить загрузку ПО снова. Если за три попытки прошить модуль управления не удалось, прекратите попытки, свяжитесь с сервисно-гарантийной службой.

# Восстановление настроек

## Установить необходимый язык

Для этого:

1. На пульте управления (MMI) нажать кнопку «ME DATA» («ИЗМЕРЕНИЕ»),
2. Затем нажать и удерживать кнопку «▲», пока на экране не появится надпись «Enter admin password» или «Введите пароль».
3. Нажать кнопку «9», затем кнопку «Enter» («Ввод»).
4. На экране должна появиться надпись «Service menu» или «Сервисное меню».
5. Затем нажать кнопку «Enter» («Ввод»), нажатием кнопки «▼» выбрать пункт «Language» или «Язык» и нажать кнопку «Enter» («Ввод»).
6. Для изменения значения нажмите кнопку «Enter» («Ввод»), затем нажатиями кнопки «▲» или «▼»  прокрутите циклический список доступных значений до появления требуемого значения.
7. Снова нажмите кнопку «Enter» («Ввод»).
8. Подтвердите изменения, ещё раз нажав кнопку «Enter» («Ввод»).

## Настройка подфункциональности терминала

1. В основном меню выбрать пункт «Settings» или «Настройки» и нажать кнопку «Enter» («Ввод»).
2. Выбрать «System» или «Системные параметры» и нажать кнопку «Enter» («Ввод»).
3. Выбрать пункт «Configuration» или «Конфигурация» и нажать кнопку «Enter» («Ввод»),
4. Затем нажатием кнопки «▲» или «▼» прокрутите до пункта «Subfunctionality» или «Подфункциональность».
5. Снова нажмите кнопку «Enter» («Ввод»),
6. Затем нажатием кнопки «▲» или «▼» прокрутите до необходимой подфункциональности
7. Подтвердите изменения, ещё раз нажав кнопку «Enter» («Ввод»).

# Проблемы и решения

## Как зайти в сервисное меню «Service menu».

**Решение:**

1. Для входа в сервисное меню на пульте управления (MMI) нажать кнопку «ME DATA» («ИЗМЕРЕНИЕ»),
2. Затем нажать и удерживать кнопку «▲», пока на экране не появится надпись «Enter admin password» или «Введите пароль».
3. Нажать кнопку «9», затем кнопку «Enter» («Ввод»).
4. На экране должна появиться надпись «Service menu» или «Сервисное меню»,
5. Затем зажать и держать кнопку «стрелка вверх» до запроса модулем пароля «Enter admin password».
6. Нажать кнопку «9», затем нажать кнопку «ENTER». Отобразится «Service menu».

## Как проверить PING

**Решение:**
1\) Нажмите на ПК сочетание кнопок Win+R
2\) В появившемся окне «Выполнить» в строке «Открыть» введите команду cmd и нажмите OK

| :---------------------------------------------------------------: |
|                **Рис. 15** Вызов командной строки                 |

3. В появившейся командной строке ввести команду ping и IP-адрес модуля управления. IP-адрес по умолчанию для Wi-Fi «192.168.100.11», для Ethernet «192.168.102.11».

## При подключении TELARM Lite соединение не устанавливается, в области Подключение к устройству появляется сообщение:

<span style="background-color: gray; color: red; padding: 6px 10px; border-radius: 4px; line-height: 1.8;">
  <b>Ошибка сокета. Попытка установить соединение была безуспешной, т.к. от другого компьютера за требуемое время не получен нужный отклик, или было разорвано уже установленное соединение из-за неверного отклика уже подключенного компьютера</b>
</span>

**Решение:** Убедиться, что IP-адреса в устройстве и в TELARM Lite совпадают (IP-адрес по умолчанию для Wi-Fi «192.168.100.11», для USB-MMI «192.168.101.11», для Ethernet «192.168.102.11»). Убедиться в наличии соединение между ПК и CM, выполнить проверку PING (см. п.2 Приложение 1) с IP-адресом устройства.

В случае повторения ошибки проделать следующие манипуляции:

1. Проверить уровень сигнала Wi-Fi. Если сеть Wi-Fi прошиваемого блока не обнаруживается на ПК, то выключить и включить Wi-Fi в меню «Управление c панели» «Системные параметры». После выполнения операций в меню должна остаться надпись “Wi-Fi отключить” (это значит, что Wi-Fi включен сейчас, а выбор данного пункта отключит его).
2. Убедиться, что модуль управления включен, на модуль управления подано оперативное питание (на каждый разъем X2, X5, X8, X11), все светодиоды POWER горят.
3. Убедиться, что соединение с модулем управления и ПК установлено на рабочем оборудовании.
4. Убедиться, что в настройках сети ПК для сети Модуля управления установлено автоматическое получение IP-адреса или установлен разрешенный IP-адрес.
