# Назначение

Защита минимального напряжения ЗМН2 совместно с АПВ ЗМН2 применяется для локализации повреждённых участков сети путём отключения в бестоковую паузу и последующей автоматической двунаправленной сборки.

| :----: | :----------------------------------: | :---------------------: | :-----------------------------------------------------------: | :----------: |
|  ЗМН2  |                  -                   |      Режим работы       | Выведено / Прямая <br>последовательность<br>/Фазное /Линейное |   Выведено   |
|        |            $U_{р}$, о.е.             | Напряжение срабатывания |                            0,5 - 1                            |     0,6      |
|        |               $T_t$, с               |   Время срабатывания    |                             0-360                             |      1       |
|        |                  -                   |  Блокировка по питанию  |                     Введена/<br>Выведена                      |   Выведена   |
При помощи настройки «Режим работы» имеется возможность вывести ЗМН2 из работы. Также этой настройкой выбирается величина, при снижении которой работает защита. При выборе режима работы по фазному (линейному) напряжению для пуска ЗМН2 достаточно снижение одного из фазных (линейных) напряжений.

При помощи настройки «Блокировка по питанию» возможно ввести блокировку ЗМН2 при отсутствии напряжения.

# Условия срабатывания и возврата

## Условия срабатывания

- Для режима "Прямая последовательность"

$$
U_1 ≤ \frac {U_р \cdot U_{ном}} {\sqrt{3}} ,\quad \text {где}
$$

$U_р$ — напряжение срабатывания ступени, о.е.,
$U_1$ — напряжение прямой последовательности,
$U_{ном}$ — номинальное напряжение сети.

- Для режима "Фазное напряжение"

$$
U_a ≤ \frac {U_р \cdot U_{ном}} {\sqrt{3}},\quad \text {где}

$$

$Ua$— фазное напряжение. Для фаз B и C условия аналогичны.

- Для режима "Линейное напряжение"

$$
U_{ab} ≤ U_р \cdot U_{ном},\quad \text {где}
$$

$Uab$ - линейное напряжение. Для напряжений Ubс, Uсa условия аналогичны.

## Условия возврата

Возврат защиты происходит при:

- Для режима «Прямая последовательность»:

$$
U_1 > 1,02 \cdot \frac {U_р \cdot U_{ном}} {\sqrt{3}}
$$

- Для режима «Фазное напряжение»:

$$
U_a > 1,02 \cdot \frac {U_р \cdot U_{ном}} {\sqrt{3}}
$$

- Для режима «Линейное напряжение»:

$$
U_{ab} > 1,02 \cdot U_р \cdot U_{ном}
$$
